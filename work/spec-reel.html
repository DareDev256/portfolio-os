Spec Reel 2026

Thirty unsolicited commercials for real brands — brief to finished 87-second reel in a single session, for about US$21. One human tension, one strategic turn, one line, six seconds of screen, thirty times over.

1920×1080 · 2.39:1 · 86.75s · 30 spots + end card

Spec work. Every brand shown is real; none of them commissioned, reviewed or approved any of this. These are unsolicited concepts, the way a portfolio book has always carried them. Nothing here has run anywhere.
Status

Solo — strategy, art direction, prompt engineering, pipeline, edit

Stack
Gemini 2.5 Flash Image (keyframes) · Kling 2.1 via fal.ai (motion) · ffmpeg (cut) · Python harness
Why it exists
To show brand thinking at volume, and the engineering that makes volume repeatable rather than lucky

The rule every spot had to pass

Generative tools make it trivial to produce thirty pretty frames and zero ideas. So the constraint came first, and it was written before a single image was made: each spot names a human tension that is true whether or not the brand exists, a strategic turn that does something with it, and one line. The picture is the last thing decided, not the first.

Colour was also decided up front — a committed ground plus exactly one loud accent per spot, chosen before composition. That is what keeps thirty frames from collapsing into the same tasteful neutral wash.

How it was actually made

One Python file holds all thirty spots as data and regenerates both the human-readable bible and the JSON that drives generation. Everything downstream is resumable and spend-capped, because the interesting failure mode of this kind of work is not a bad frame, it is a bad frame you paid for thirty times.

StepWhat it does
1Keyframe stillsGemini image API, resumable, ffprobes every file it writes
2MotionKling 2.1 image-to-video on fal, all 30 submitted concurrently, request IDs journalled to disk at submit time
3RecoveryRe-fetches already-billed clips from the journal when a run dies
4Cutffmpeg — autocrop, 2.39:1 letterbox, lower third, end card

Kling costs about US$0.28 for five seconds. Veo 3.1 Fast is US$0.12/second and only serves 1080p at eight seconds, so US$0.96 a clip — four times the price for motion that tested no better on this material. That comparison was run, not assumed.

What went wrong, since that is the actual work

The image API silently ignored the aspect ratio. The prompt opened with “1920×1080, 16:9, do not generate a square image” and it returned 1024×1024 — forty-five times, with no error. Aspect ratio is an API parameter, not a sentence. Every still is now ffprobed after it is written.

Worse, the contact sheets used for review were built with an ffmpeg crop, so they rendered the square frames as 16:9. The review artifact performed the exact transformation whose absence it was supposed to detect. Two paid render batches ran on bad frames before that surfaced.

Then two separate luminance harnesses reported an opaque black box as identical to no box at all, because scaling an image to 1×1 does not average it. The fix is dull and non-negotiable: run a known control through the instrument before trusting a single reading from it.

None of this is unique to advertising. It is the same failure in every automated pipeline — a check that cannot see the thing it is checking for reports success either way.

What I would do next

Shoot the three weakest spots properly rather than generate them; the gap between a generated frame and a directed one is still widest on faces and hands. Build a per-brand reference sheet so the same product reads identically across spots. And cut a thirty-second version, because eighty-seven seconds is a portfolio length, not a feed length.
