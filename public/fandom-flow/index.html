The agent reads User:RawBOT/shutoff before it reads anything else. If the first line of that page is not exactly RUN, the run aborts without touching the wiki. That page is currently editable by any editor, and every change to it is public in the page history. The bot's own credentials cannot alter that protection — its login is granted edit and move but not protect, so the agent cannot widen its own leash.

how to halt it

why

The block log

On Wikipedia the bots blocked for "no emergency button" and "not responding to the run page" were the ones whose switch did not work. A switch nobody can reach is not a switch.

rate

One edit per day

One edit per UTC day, never flagged bot so every change stays visible in Recent Changes. Operator: James Dare, reachable on the account's talk page.

The scheduled job is an applier, never an author. It cannot invent an edit. It drains a queue written and reviewed in advance, and if that queue is empty it writes a dated line in its own userspace rather than improvising in article space.

01 - session

Research & queue

Edits are researched against patch notes and the game, then written to queue.jsonl with the exact operation, expected match count, and a citation.

02 - 09:00 daily

Verify premise

A queue entry is a hypothesis. Before firing, the job re-reads the live page and confirms the premise still holds. Drifted page, blocked entry.

03 - apply

One edit

One edit per UTC day, never flagged bot. If a human already edited that day, the job exits without touching anything.

04 - independent

Verify result

A separate reader queries the wiki and counts distinct edit-days. It reads no state file, no log, no queue - only what the wiki says happened.

A constraint that has never been observed to fire is indistinguishable from a comment in the code. Each one below is exercised by a test that tries to make it fail — the guard passes only by refusing. The last row is a control: a correctly-declared edit that must still go through, so a suite that refused everything could not pass.
